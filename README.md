# Inkbow

Rainbow and gradient text generator that exports BBCode, HTML, CSS, ANSI and Minecraft codes. Single static file, no build step.

Made by **AziF**.

## Deploy to GitHub Pages
1. Create a repo and push these files to `main`.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. The included workflow publishes the site at `https://<user>.github.io/<repo>/`.

Run locally: open `index.html` in a browser.
